## 01 / Game Identity & Vision

| Parameter          | Keputusan                                |
| ------------------ | ---------------------------------------- |
| Judul / codename   | The Hollow Japan / THJ                   |
| Genre / tema       | Open World Action RPG / Japanese Fantasy |
| Setting / atmosfer | Feudal Japan Fantasy / Mixed Fantasy     |
| Perspektif / tile  | Top-down 2D / 16 × 16 px                 |
| Karakter / class   | Custom Character / Classless             |
| Cerita / combat    | Branching / Real-time + Tactical Pause   |
| Dunia              | Handcrafted + Procedural                 |
| Mode               | Offline singleplayer; online co-op 2–4   |
| Difficulty         | Challenging                              |
| Platform           | Linux dan Windows                        |
| Teknologi          | C++, SDL3; C++23 dan CMake diusulkan     |

### Visi

Pengembara dengan kemampuan memasuki dunia manusia dan roh menjelajahi kepulauan fiktif, mengembangkan kemampuan tanpa class permanen, serta menentukan nasib dunia melalui pilihan dan hubungan faction.

### Design pillars

Exploration, Combat, Consequences, Duality, Freedom, Cooperation.

### Fitur pembeda dan tambahan

Dual Realm, Hollow Corruption, faction & reputation, spirit companion, weapon mastery, player housing, dynamic world events, crafting dan profesi (blacksmithing, alchemy, cooking, fishing, farming, gathering). Housing dan profesi diprioritaskan setelah core gameplay stabil.
